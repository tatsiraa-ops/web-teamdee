## เจตนา

ราคาและเงื่อนไขสกรีนบนเว็บ (เริ่ม 1 ตัว · 290 บาท · ทุกไซซ์ราคาเดียว · 3–14 วัน) ไม่ตรงกับที่เซลล์เสนอจริงแล้ว
ลูกค้าที่เห็นราคาบนเว็บแล้วทักมาจะได้ราคาไม่ตรง → เสียความเชื่อใจ
เป้าหมาย: ราคา ขั้นต่ำ วันผลิต และเงื่อนไขบนเว็บ = สไลด์ทุกตัวเลข และเครื่องคำนวณให้ยอดเท่ากับที่เซลล์คิด

4. 1 ลาย: ลายเดิมต่างขนาดรวมจำนวนได้ แต่คิดราคาตามขนาด · ลายต่างกันไม่รวมจำนวน · ลายเดียวกันต่างสีเสื้อ/ต่างไซซ์รวมได้

## เครื่องคำนวณ (/calculations/ + ลิงก์จากหน้าสกรีน)

ช่องกรอก: บริการ (เสื้อ + สกรีน / สกรีนบนเสื้อของคุณ) → รุ่นเสื้อ (C32 / Oversize · เฉพาะบริการแรก) → จำนวนตัว → ลายจุดที่ 1–3 (เลือกขนาด · เพิ่ม/ลบจุด) → จำนวนตัวไซซ์ 2XL ขึ้นไป (เฉพาะ C32)
ผลลัพธ์: ราคาต่อตัว · ยอดรวม · แตกรายการ (จุดแรก · จุดเพิ่ม · Oversize · ไซซ์ใหญ่ · ค่าส่ง) · วันผลิต · แผนชำระ · ปุ่มส่งใบประเมินทาง LINE (ข้อความมีรายละเอียดครบ)
กรณีพิเศษ: ต่ำกว่าขั้นต่ำ = บอกขั้นต่ำ · เกิน 1,000 / เกิน 3 จุด = "ทักทีมดีประเมิน" · แต่ละตัวสกรีนไม่เท่ากัน = หมายเหตุ "ทักทีมดีคิดให้"
ลิงก์เดิม ?kind=screen / ?kind=screen-oversize ต้องยังเปิดได้ (แปลงเป็นบริการแรก + รุ่นเสื้อที่ตรง)

## การตัดสินใจของผม (อาร์ตแก้ได้)

- "ฟ้า (รอเช็กสต็อก)" ขึ้นเว็บเป็น "ฟ้า · สอบถามสต็อก"
- "รับของเองที่ HUB" + เวลาทำการ HUB ไม่ขึ้นเว็บ (ยังไม่มีที่อยู่ HUB ที่เปิดเผยได้)

- ขอบเขต "เกิน 3 จุด" / "ตำแหน่งพิเศษ" / "แต่ละตัวสกรีนไม่เท่ากัน" ในเครื่องคำนวณ = ให้ทัก LINE ไม่คำนวณ
