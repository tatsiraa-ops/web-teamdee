> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ทำหน้า /custom-staff-shirts/ (ร้านค้า), /custom-organization-shirts/ (หน่วยงาน), /education/ (โรงเรียน) ให้เป็นโฉมเดียวกับ /corporate/ และหน้า /embroidery/ (ปัก) ให้เป็นโฉมเดียวกับ /sublimation/ โดยปักทำท้ายสุด

**Architecture:** ระบบรองรับอยู่แล้ว หน้ากลุ่มจะเปลี่ยนเป็นโฉมใหม่ทีละส่วนตามคีย์ที่มีใน `src/data/use-v2.json[<กลุ่ม>]` (ตอนนี้มีแค่ `corp`) ส่วนหน้าสินค้าใช้ `src/data/pp-v2.json[<สินค้า>]` (ตอนนี้มีแค่ `print`) งานหลักจึงไม่ใช่การ copy template แต่มี 3 อย่าง: (1) ล้างคำว่า "บริษัท" ที่ฝังตายตัวไว้ใน partial `up2*` (2) เติมข้อมูลและรูปของแต่ละกลุ่ม (3) ปรับเทส corp ให้วนตรวจทุกกลุ่ม

**Tech Stack:** Vite + Handlebars → WP export · node --test · รูปเจนผ่าน Magnific (GPT 2.5 high สำหรับแบนเนอร์/ฉาก)

**Spec:** หน้า /corporate/ และ /sublimation/ ที่อาร์ตอนุมัติแล้ว (PLAN.md รอบ 43–201) + ข้อความอาร์ต 11 พ.ย. 2026 "หน้าหลักเสร็จหมดแล้ว เหลือ duplicate ทำซ้ำในหน้าอื่นๆ · เอาหน้างานปักไว้ท้าย"

## Global Constraints

- ห้ามแต่งข้อเท็จจริง ราคา หรือคำรีวิว: รีวิวมาจาก `reviews.json` เท่านั้น ถ้ากลุ่มไหนมีน้อยก็แสดงเท่าที่มี
- ห้ามใช้คำว่า "โรงงาน"
- คนที่เป็น AI ห้ามดูเหมือนลูกค้า: ภาพเจนต้องมีป้าย "ภาพจำลอง" หรือ alt ขึ้นต้นด้วย "ภาพจำลอง…"

- `_drive/` (ไฟล์งานปักลูกค้า) ยังไม่ได้รับอนุญาตให้ใช้
- git: ไม่ commit เอง ทำจบแต่ละ task แล้วรายงานว่า "พร้อม commit"

## Review Focus

1. **คำว่า "บริษัท/องค์กร" หลุดไปหน้าอื่น**: หน้าร้านค้า/หน่วยงาน/โรงเรียนต้องไม่มีคำนี้ในหัวข้อหรือป้ายใดเลย → Task 1 มีเทสสแกนทั้งหน้า
2. **รูปซ้ำในหน้าเดียวกัน**: hero, แท็บ, คลังรีวิว, showroom ต้องไม่ใช้รูปเดียวกันซ้ำ (เคยเกิดบน corp) → ทุก task ใช้เทสรูปไม่ซ้ำที่วนทุกกลุ่ม
3. **กลุ่มที่รีวิวน้อยมีส่วนรีวิวโล่ง**: ร้านค้ามี 1 รีวิว ส่วนรีวิวต้องไม่มีช่องว่างหรือการ์ดเปล่า → เทสจำนวนการ์ดเท่ากับรีวิวที่มีจริง และ screenshot ตรวจ
4. **ภาพเจนไม่มีป้าย**: ฉาก diorama และ hero ต้องมีป้ายหรือ alt บอกว่าเป็นภาพจำลอง → เทสใน Task 2–4
5. **ลิงก์ข้ามกลุ่มผิด**: ปุ่มในแท็บ, showroom และ "ดูทั้งหมด" ต้องพาไปหน้าแบบเสื้อหรือรีวิวของกลุ่มตัวเอง (เช่น ร้านค้า → /staff-shirt-designs/) → เทส href ต่อกลุ่ม

## ข้อตัดสินใจที่ต้องให้อาร์ตเลือกก่อนเริ่ม

1. **ลำดับและจังหวะ:** ทำทีละหน้า (ร้านค้า → หน่วยงาน → โรงเรียน) และให้อาร์ตดูจบหน้าก่อนไปหน้าถัดไป *(แนะนำ: หน้าแรกที่ผ่านจะกลายเป็นแม่แบบ หน้าที่สองและสามจะเร็วขึ้นมาก)*
2. **ฉาก diorama ในแท็บ:** เจนใหม่กลุ่มละ 5–6 ฉาก รวม ~17 ภาพ (ใช้เครดิต Magnific) หรือใช้แค่รูปลูกค้าจริง 2 รูปต่อแท็บโดยไม่มีฉาก
3. **ภาพ hero:** เจนนายแบบใหม่ต่อกลุ่ม (เสื้อลายจริงของกลุ่มนั้น) หรือใช้ภาพบรรยากาศ `uses-row` ที่มีอยู่
4. **รีวิวที่ไม่พอ:** ใช้เท่าที่มี (หน่วยงานจะใช้ hospital ซ้ำกับ corp) หรืออาร์ตหาแชทรีวิวเพิ่มของร้านค้าและหน่วยงาน
5. **ส่วนเฉพาะของหน้าเดิม** (เช่น `design-evidence` ของโรงเรียน, `designs` แนวแบบของทุกหน้า): ตัดตาม corp หรือเก็บไว้
