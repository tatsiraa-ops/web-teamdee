# หน้า /custom-football-shirts/ — brief + ร่างข้อความ

## 0. Brief สั้น

- **ทำไมต้องมีหน้า:** keywords.md §1.2 และ §3.3 อันดับ 2 — "สั่งทำเสื้อบอล · ทำเสื้อทีมฟุตบอล" ขึ้นใน autocomplete และ competitor มีหน้าเฉพาะ ตอนนี้มีแค่แท็บ "ฟุตบอล / ฟุตซอล" ใน /sport/
- **คนอ่าน:** หัวหน้าทีม / ผู้จัดการทีม / ฝ่ายบุคคลที่ดูแลทีมบอลบริษัท / โค้ชทีมเยาวชน คนที่ต้องรวบรวมชื่อ เบอร์ ไซซ์ของทั้งทีม
- **สิ่งที่หน้าต้องตอบภายใน 1 จอแรก:** ทำชื่อ-เบอร์รายคนได้ · ขั้นต่ำ 10 ตัว · ผลิต 15–20 วัน นับจากวันถัดจากวันยืนยันแบบ · ราคาแจ้งตามแบบและจำนวน ทัก LINE
- **ราคา:** เสื้อบอลเป็นงานพิมพ์ลาย (ซับลิเมชัน) → **ห้ามใส่ราคา** ใช้ข้อความ "แจ้งราคาตามแบบและจำนวน ทัก LINE" ทุกจุด ราคาที่ใส่ได้ในหน้านี้มีแค่ Jersey Oversize (เสื้อเชียร์) และโปโลปัก (เสื้อโค้ช/สตาฟ) จาก prices.json
- **โครงหน้า:** ตาม src/content/use/sport.json ทั้งชุด `page` + `v2` (hero → trust → pain → contexts → designs → products → help → work → reviews → benefits → check/plan → payment → FAQ → team → related) เปลี่ยนแค่เนื้อหา
- **วิธีสร้าง (ทีหลัง):** `npm run new:page -- use football --from sport --route /custom-football-shirts/ --name "เสื้อฟุตบอล"` → ได้ไฟล์ src/content/use/football.json (สำเนาจาก sport) + หน้า site/custom-football-shirts/index.html ที่ติด noindex → แทนข้อความด้วยร่างนี้ → ลบ noindex เมื่อตรวจครบ
- **หลังสร้างหน้า:** ในแท็บ "ฟุตบอล / ฟุตซอล" ของ /sport/ เพิ่มลิงก์ "ดูหน้าเสื้อฟุตบอล" ไปหน้าใหม่ และใส่ในรายการ `related` ของ /custom-badminton-shirts/ และ /custom-running-shirts/

## 11. FAQ (`page.faq`) — H2 รูปคำถาม คำตอบตรงในประโยคแรก

**สั่งทำเสื้อบอลขั้นต่ำกี่ตัว?**
ขั้นต่ำ 10 ตัว ทีมฟุตซอลหรือทีมเล็กที่ยังไม่ถึง ทักมาเล่าจำนวนได้ ทีมงานจะบอกตรงว่าทำได้แบบไหน

**เสื้อบอลราคาเท่าไร?**
แจ้งราคาตามแบบและจำนวน ทัก LINE ราคาขึ้นกับจำนวน ชนิดผ้า ทรงคอ และออปชันที่เพิ่ม ราคารวม VAT ทุกไซซ์ราคาเดียว และส่งฟรีทั่วประเทศ

**ทำชื่อและเบอร์แยกรายคนได้ไหม?**
ได้ ทำชื่อและเบอร์แยกตัวได้ในล็อตเดียวกัน ไม่คิดเพิ่มต่อตัว ส่งรายชื่อ เบอร์ และไซซ์ที่ตรวจสะกดแล้วมาเป็นไฟล์ตารางครั้งเดียว

**ผู้รักษาประตูใส่สีต่างจากทีมได้ไหม?**
ได้ อยู่ในงานเดียวกัน ไม่คิดเพิ่ม แจ้งตอนสรุปไซซ์ว่าใครใส่สีไหน ทีมดีแยกให้ในล็อตเดียวกัน

**ใส่โลโก้สปอนเซอร์หลายเจ้า คิดเพิ่มไหม?**
ไม่คิดเพิ่มตามจำนวนโลโก้หรือจำนวนสี ส่งไฟล์โลโก้ทุกเจ้ามา ดีไซเนอร์จัดวางให้ดูก่อน ใช้ได้เฉพาะโลโก้ที่ได้รับอนุญาตแล้ว ทีมดีไม่รับทำงานที่ลอกโลโก้หรือลายที่มีลิขสิทธิ์ของคนอื่น

**ใช้เวลาผลิตกี่วัน?**
ประมาณ 15–20 วัน เริ่มนับวันถัดจากวันยืนยันแบบ ช่วงตุลาคม–มกราคมควรเผื่อเพิ่ม 5–7 วัน งานด่วนเร็วสุด 7 วัน ไม่มีค่าเร่ง บอกวันแข่งมา ทีมดีนับถอยหลังให้

**มีไซซ์เด็กสำหรับทีมเยาวชนไหม?**
มี เสื้อพิมพ์ลายมีไซซ์เด็ก No.4–8 และผู้ใหญ่ SS–7XL ทำในแบบเดียวกันได้ ดูตารางที่ /size-chart/

**ระหว่างฤดูกาลมีนักเตะเพิ่ม สั่งเติมได้ไหม?**
ได้ ทีมดีเก็บสเปกและไฟล์งานไว้ รอบถัดไปแจ้งแค่ชื่อ เบอร์ และไซซ์ สั่งเพิ่มแบบเดิมภายใน 30 วันหลังรับเสื้อได้ราคาเดิม ผ้าต่างล็อตสีอาจต่างเล็กน้อย [ต้องยืนยัน: ขั้นต่ำรอบสั่งเติม]

**ลายจะลอกเมื่อซักบ่อยไหม?**
ไม่ลอก เพราะสีซึมเข้าไปอยู่ในเส้นใยผ้า ไม่ได้เคลือบทับบนผิว แต่ผ้าทุกชนิดจะซีดลงตามอายุใช้งานและการตากแดด ซักเครื่องได้ แนะนำน้ำเย็น กลับด้านใน ไม่ใช้น้ำยาฟอกขาว และตากในร่ม

**เสื้อวอร์มกับเสื้อเชียร์ใช้ลายเดียวกับเสื้อแข่งได้ไหม?**
ได้ ใช้สีและแนวกราฟิกร่วมกัน แล้วปรับให้เข้ากับทรงเสื้อวอร์มหรือเจอร์ซีย์ Oversize ส่วนเสื้อเชียร์เลือกแยกจากเสื้อแข่งได้ เพราะเสื้อแข่งเน้นการเคลื่อนไหว เสื้อเชียร์เน้นรูปแบบ
