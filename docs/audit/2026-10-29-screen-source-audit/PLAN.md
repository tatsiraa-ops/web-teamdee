## ช่องว่างของ TEAMDEE ที่เติมได้

`src/data/products.json` ของ screen ยังมี img ว่าง และข้อความต้องการภาพจริง ข้อมูลผ้า รายละเอียด และเคสใน `src/data/product-pages.json` หลายส่วนยังเป็นร่าง ซึ่งระบบ export ซ่อนบางส่วนไว้ จึงไม่ได้หมายความว่าข้อความร่างทั้งหมดปรากฏบนเว็บจริง

1. **หน้าแรก:** แทนภาพประกอบเสื้อสกรีนด้วยเสื้อจริงหนึ่งตัวขนาดใหญ่ ใต้ภาพใช้รายละเอียดลาย/ผิวงานหนึ่งชิ้น คงความสูง ขอบมน และระยะข้อความเดียวกับอีกสองการ์ด หัวข้อ “รับทำเสื้อสกรีน” + คำอธิบายสั้น + “ดูเสื้อสกรีน →” ไม่เพิ่มตารางราคาในการ์ด
2. **หน้าบริการ /screen-printing/:** เติมภาพจริงให้ส่วนบน และจัดเนื้อหาช่วยเลือกเป็นตัวเสื้อ → สี → ตำแหน่งลาย → ตัวอย่างจริง → ข้อมูลส่งขอราคา รักษารูปแบบหัวข้อ ปุ่ม LINE ความกว้างและตัวอักษรของ TEAMDEE มีภาพใหญ่สลับรายละเอียด ไม่ทำทุกส่วนเป็นกล่องแบบเดียวกัน
3. **ส่วนเลือกผ้า/ทรง:** ใช้ภาพเสื้อและผ้า พร้อมเทียบ Premium Cotton กับ Oversize เจ้าของงานยืนยันแล้วว่า TEAMDEE ใช้ตัวเสื้อเดียวกัน ภาพต้นทางระบุ C32 Comb และ C20 Comb แต่ยังไม่ควรแปลงเป็น GSM หรือรับรองคุณสมบัติที่ไม่ได้มีหลักฐาน
4. **ตำแหน่งสกรีน:** แปลงข้อมูลโปสเตอร์เป็นแผนภาพเรียบในสี TEAMDEE เริ่มจากอกซ้าย กลางอก หลัง แขน แสดงพร้อมกันบนมือถือ แยกขนาดลายออกจากตำแหน่ง ใช้ขนาดลายตามตารางที่ตรวจเพิ่มใน CONTENT.md ลูกค้าเลือกแล้วใช้ประกอบข้อความขอราคาได้
5. **ผลงานจริง:** เริ่ม 3 ชุดที่มีภาพรวมและภาพใกล้ เช่น งานโลโก้บริษัท งานตัวอักษร และงานหลายสี บรรยายเฉพาะที่เห็น ไม่แต่งจำนวนผลิต ระยะเวลาส่ง หรือรีวิว ให้ภาพขยายได้โดยไม่บังคับเลื่อนหลายชั้น
6. **คลังแบบเสื้อ:** ใช้ 486 ไฟล์เป็น inventory สำหรับคัด ไม่เทลงหน้าแรกทั้งหมด เริ่มชุดนำ 12–18 แบบ แยกตามการใช้งาน มีรหัสแบบและลิงก์ส่งแบบให้ทีมดี ต้องระบุเป็นแบบจำลอง และยังต้องตรวจทุกภาพที่นำขึ้นจริง
7. **คู่มือสกรีน / คู่มือเตรียมไฟล์ / บทความ DFT เดิม:** ใช้ภาพใกล้จริงอธิบายรายละเอียดไฟล์ สี ตำแหน่งและการดูแล เพิ่มลิงก์กลับบริการ คง URL เดิม ไม่สร้างบทความเนื้อหาซ้ำแข่งกัน ข้อมูลสำคัญเขียนเป็น HTML ไม่ฝังอยู่เฉพาะโปสเตอร์ภาพ
8. **หน้ากลุ่มลูกค้า:** บริษัทใช้โลโก้อก–หลัง ร้านค้าใช้ตัวอย่างร้าน มหาวิทยาลัยใช้ลายคณะ เชื่อมกลับหน้าสกรีนและคู่มือ โดยไม่เปลี่ยนดีไซน์ทั้งเว็บในรอบเดียว
9. **วิดีโอ:** คัดคลิปจริงก่อน แล้วใช้คลิปสั้นหนึ่งชิ้นในส่วนรายละเอียด/การผลิต มีภาพปกและกดเล่น โหลดเมื่อผู้ใช้ต้องการ ไม่มีวิดีโอหนักเล่นอัตโนมัติในทุกการ์ด

บนมือถือให้ภาพหลักและตัวเลือกสำคัญแสดงตามแนวตั้ง ตัวเลือกย่อยใช้กริดที่เห็นครบ ไม่ทำ carousel ซ้อน carousel ปุ่มขอราคาคงข้อความและหน้าตาของ TEAMDEE และแนบสิ่งที่เลือกเท่าที่ระบบรองรับจริง

## ลำดับทำที่แนะนำ

รอบแรกทำการ์ดหน้าแรกและตัวอย่างหน้าบริการสกรีนด้วยภาพจริง 6–8 ภาพให้ตรวจบน 375px และ 1440px ก่อน จากนั้นจึงขยายไปคลังแบบ คู่มือ และหน้ากลุ่มลูกค้า ไม่แตะ hero นายแบบ/นางแบบและบริการอื่นโดยไม่เกี่ยวกับงานนี้

ตัวเสื้อและเงื่อนไขขายร่วมกันได้รับการยืนยันแล้ว ระยะผลิตและรายการสีได้รับการยืนยันเพิ่มเติมแล้ว รายการรวมในราคาตรวจพบแล้ว เจ้าของงานยืนยันราคาปกติแล้ว สเปกและสี Oversize ยืนยันแล้วว่า C20 ขาว/ดำ เหลือตารางไซซ์ที่รอฝ่ายผลิต และคำบรรยายความสัมพันธ์ของทีม/พื้นที่ผลิตในภาพ โดยไม่ต้องถามซ้ำเรื่องใช้ตัวเสื้อและเงื่อนไขร่วมกัน
