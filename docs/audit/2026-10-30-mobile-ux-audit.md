# ตรวจการใช้งานมือถือ "ให้ดีกว่า ไม่ใช่แค่รองรับ" (30 ต.ค. 2026)

อาร์ตสั่ง: "ไปตรวจการใช้งานทั้งในมือถือ … ไม่ใช่แค่รองรับ ต้องทำให้ได้ดีกว่าเลย ไปตรวจสอบและเสนอมา"
วิธี: agent 5 ตัว ตรวจคนละมุม บน build จริง (localhost:4173) ที่ 320/360/375/390 และแนวนอน 812×375
1. ใช้งานจริงตั้งแต่ต้นจนจบ 7 เส้นทาง
2. ความเร็วมือถือ
3. นิ้ว การอ่าน ท่าทาง และ a11y
4. เนื้อหา IA และ conversion
5. เทียบเว็บต่างประเทศและคู่แข่งไทย

ข้อที่สำคัญ ผม (Claude) ตรวจซ้ำเองกับไฟล์ build แล้ว ข้อที่ตรวจซ้ำแล้วมีเครื่องหมาย ✔
**ยังไม่ได้แก้อะไร รอเคาะ**

## ภาพรวม
- **ฐานดีแล้ว**: ไม่ล้นจอแม้ที่ 320px · ฟอร์มใช้ประเภทคีย์บอร์ดถูก · มี skip link · H1 หน้าละ 1 · รูปมี alt · ปุ่มย้อนกลับปิดหน้าต่างได้ · CLS ≈ 0 ทุกหน้า
- **หน้าที่ดีที่สุด /embroidery/**: จอแรกมีราคา ขั้นต่ำ วันผลิต ภาพลูกค้าจริง และปุ่ม LINE ปุ่มเดียว ใช้เป็นสูตรของหน้าอื่นได้
- **/calculations/ ทำได้ดีที่สุดเรื่อง LINE**: ข้อความที่ส่งมีสินค้า จำนวน ราคา และยอดรวม แถบล่างแสดงยอดสด
- **นำคู่แข่งไทยที่ดูมาแล้ว**: มีตารางราคาจริงรวม VAT, เครื่องคิดราคา, รหัสแบบ, ข้อความ LINE ที่เติมให้ ส่วนคู่แข่งส่วนใหญ่ไม่บอกราคา และปุ่มไปลิงก์ LINE เปล่า
- **ที่ยังทำให้เสียลูกค้า**: ข้อมูลตัดสินใจไม่อยู่บนจอแรกของบางหน้า · ปุ่มที่คนกดมากที่สุดไม่ส่งบริบท · ชั้นที่ลอยอยู่บนจอบังกันเอง · ส่งต่อให้หัวหน้าไม่ได้ · ท่าทางยังไม่เหมือนแอป

## ข้อที่ต้องให้อาร์ตเคาะก่อนลงมือ
1. ปุ่มหลักหน้า /corporate/ และ /education/ เปลี่ยนจาก "ขอใบเสนอราคา (ฟอร์ม)" เป็น LINE ไหม
2. ป๊อปอัปบนมือถือ: ขึ้นเมื่อเลื่อนเกิน 50% / เป็นแถบเล็กในเนื้อหา / ไม่แสดงบนมือถือ
3. แถบความเชื่อมั่นหน้าแรกมี "ปรับแบบฟรี · ผ้าตัวอย่างฟรี · จัดส่งฟรี · เคลมงานผลิตฟรี" — นับเป็นข้อเท็จจริง (ใช้ต่อ) หรือโปร (กฎห้าม "ฟรี")
4. "ตอบภายใน 5 นาที" เป็นจริงทุกช่วงเวลาไหม (ถ้าไม่ ควรเขียนเวลาทำการ)
5. วิธีชำระเงินที่รับจริง: มัดจำ 50% ทุกงานไหม · โอน · PromptPay · บัตร · วางบิล
6. /corporate/ ใช้รูปโปโลปักองค์กรที่อนุมัติแล้วจากหน้า /embroidery/ ได้ไหม
7. ตารางไซซ์จริงของเสื้อพิมพ์ลาย/สกรีน/เบสบอล/วอร์ม/Jersey (ตอนนี้บนเว็บจริงไม่มีในหน้าสินค้า) — ขอไฟล์จากโรงผลิต
8. ตั้งค่า Cloudflare (ข้อ 26): ใครดูแลบัญชี
