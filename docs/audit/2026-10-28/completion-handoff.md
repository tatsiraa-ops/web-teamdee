## พร้อมให้ลอง
- แก้สามข้อจากรายงานก่อนหน้า: Thank you ไม่อ้างรับฟอร์มเมื่อเปิดตรง, ค้นหารวมพบ 12 บทความเดิม, ลิงก์สเปกเสื้อจากคลังแบบชี้ #options
- คลังร้านค้า รุ่น/ชมรม คณะ/มหาวิทยาลัย: กลุ่มละ 4 แนวทางจากแบบเดิม พร้อมแยกจากหลักฐานลูกค้าของกลุ่มนั้น ไม่เปลี่ยน customer tags
- หน้ารายละเอียดต้นแบบครบ 31 แบบ ที่ /design-preview/td-…/; ต่อฟอร์มพร้อมรหัสแบบแล้ว
- หน้ารวมตรวจ /ui/readiness/ รวมลิงก์แบบและบทความทั้งสี่เรื่อง
- หน้ารายละเอียดต้นแบบและหน้ารวมตรวจไม่ถูกส่งออกเข้า WordPress และไม่อยู่ใน sitemap
- บทความร่างยัง noindex; เอาวันที่อัปเดตที่ไม่มีหลักฐานและ Article schema ของร่างออก
- ตารางไซซ์กลางมีสถานะ draft; WordPress ซ่อนตัวเลขจนกว่าฝ่ายผลิตยืนยัน ต้นแบบยังแสดงพร้อมคำเตือน
- เพิ่ม fallback redirect /serviecs/ → /services/ และ /terms/ → /terms-conditions/ เฉพาะ old URL ที่ 404 และปลายทางมี page publish จริง; ไม่จับ POST
- รายการ 44 URL เดิมและความพร้อมข้อมูลตรวจซ้ำด้วย node scripts/check-readiness.mjs

## ยังไม่ถือว่าเสร็จบนระบบจริง
- รหัส TD เป็นรหัสอ้างอิงของต้นแบบ ยังไม่ใช่รหัสจากฝ่ายออกแบบ จึงไม่สร้าง URL สาธารณะจากรหัสเหล่านี้
- คลังแนะนำทั้งสามยัง noindex รอชุดแบบเฉพาะกลุ่มจริง
- บทความทั้งสี่รอผู้ใช้ตรวจเนื้อหา; ยังไม่ได้เปิด index หรือประกาศว่าเผยแพร่
- 12 บทความเดิม + 3 หมวด + หน้า CMS เก่า ต้องตรวจบน staging; ไม่สร้างเนื้อหาปลอมทับของเดิม
- ตารางไซซ์จริงและวิดีโอต้นฉบับ 8 รายการรอข้อมูลตามที่ผู้ใช้แจ้ง มี CSV รับข้อมูลใน docs/content-intake
- อีเมลเข้า, GTM event จริง, consent, redirects บน WordPress และ SEO plugins รอตรวจ staging
- เครื่องไม่มี PHP จึงยังไม่ได้รัน PHP test; การ build และ JS tests ไม่ยืนยัน runtime PHP
