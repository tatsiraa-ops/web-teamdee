---- block 1  title=[]
   PRODUCTION TECHNIQUES
H1 รับสกรีนเสื้อ DFT / DTF
   และงานสกรีนดิจิทัลคุณภาพสูง
   เปลี่ยนลายกราฟิกให้คมชัดบนเสื้อทุกประเภท ปลดล็อกทุกขีดจำกัดเรื่องสีสันและเนื้อผ้า ด้วยเทคโนโลยีงานพิมพ์ฟิล์มดิจิทัล

---- block 2  title=[]
   THE CORE VALUE
H2 จุดเด่นที่เหนือกว่าของงานสกรีนฟิล์มดิจิทัล
   (DFT / DTF)
   DFT (Direct to Film) คือนวัตกรรมสกรีนดิจิทัลที่พิมพ์ลายลงบนแผ่นฟิล์มก่อน แล้วจึงนำลายนั้นไปถ่ายโอนลงบนเนื้อผ้าด้วยความร้อน
   เทคนิคนี้ช่วยสร้างชั้นลายพิมพ์บนฟิล์ม ทำให้กราฟิกถูกถ่ายทอดลงบนเสื้อได้อย่างคมชัด สีสด และมองเห็นรายละเอียดที่ซับซ้อนได้อย่างชัดเจน
   รองพื้นด้วยหมึกขาว
   หมึกขาวช่วยให้ลายพิมพ์มีความทึบ สีไม่เพี้ยน และไม่ถูกกลืนไปกับสีของเสื้อ
   โดดเด่นทั้งผ้าสีเข้มและสีอ่อน
   สกรีนได้สวยงามและอ่านง่าย ไม่ว่าจะเป็นเสื้อสีขาวสว่าง หรือเสื้อสีดำเข้มจัด
   ตอบโจทย์ทุกเนื้อผ้า
   มีความยืดหยุ่นสูง สามารถทำได้ทั้งผ้าคอตตอน (Cotton), โพลีเอสเตอร์ (Poly) และผ้าผสม

---- block 3  title=[]
   BEST APPLICATIONS
H2 งานแบบไหนที่เหมาะกับเทคนิค
   การสกรีน DFT
   ปลดล็อกข้อจำกัดของงานสกรีนแบบเดิมๆ เทคนิค DFT เหมาะอย่างยิ่งสำหรับงานที่ต้องการรายละเอียดสูง และความแม่นยำของสีสัน
H3 โลโก้รายละเอียดสูง(Complex Logos)
   เส้นบางเฉียบ ตัวหนังสือขนาดเล็ก หรือลายที่มีรายละเอียดซับซ้อน DFT สามารถเก็บครบทุกรายละเอียดได้อย่างแม่นยำ
H3 กราฟิกไล่เฉดสี(Gradient Graphics)
   ลวดลายที่มีหลายสี การแรเงา หรือการไล่โทนสีแบบ Gradient ซึ่งการสกรีนบล็อกแบบเดิมทำได้ยากและมีต้นทุนสูง
H3 ชื่อทีมและองค์กร(Team Names)
   สกรีนชื่อทีม แผนก หรืองานตัวอักษรเฉพาะจุดได้คมชัด สวยงาม เหมาะสำหรับการทำเสื้อทีมหรือชุดยูนิฟอร์มพนักงาน
H3 เบอร์เสื้อกีฬา(Jersey Numbers)
   ทนทาน สีสันสดใส และขอบคมชัด เหมาะสำหรับงานสกรีนหมายเลขบนเสื้อกีฬาหรือเสื้อแข่งขันที่ต้องการความโดดเด่น

---- block 4  title=[]
   PRODUCTION PROCESS
H2 4 ขั้นตอนกระบวนการสกรีน DFT
   ที่แม่นยำทุกองศา
   งานสกรีน DFT ของเราควบคุมด้วยระบบดิจิทัลและเครื่องจักรที่ได้มาตรฐาน ตั้งแต่การเตรียมไฟล์ไปจนถึงอุณหภูมิการรีด เพื่อให้สีสด คมชัด และติดทนนาน
   01
H3 File Preparation
   (เตรียมไฟล์ดิจิทัล)
   ทีมออกแบบตรวจสอบลาย ขนาด สี และตำแหน่งที่ต้องการสกรีนอย่างละเอียด เพื่อให้ไฟล์ภาพมีความคมชัดและเหมาะสมกับขนาดเสื้อในการใช้งานจริงมากที่สุด
   02
H3 PET Film Printing
   (พิมพ์ลายลงแผ่นฟิล์ม)
   พิมพ์ลวดลายลงบนแผ่นฟิล์ม PET เฉพาะทาง โดยเครื่องจะพิมพ์สีของลายก่อน แล้วจึง พิมพ์หมึกขาวทับเป็นชั้นรองพื้น เพื่อให้สีทึบและชัดเจนแม้สกรีนลงบนเสื้อสีดำ
   03
H3 Hot Melt Powder
   (เคลือบผงกาวความร้อน)
   โรยผงกาวให้ยึดเกาะกับหมึกขาวด้านหลังฟิล์ม จากนั้นนำไปผ่านความร้อนอย่างสม่ำเสมอ เพื่อให้กาวละลายเคลือบติดกับลาย ซึ่งเป็นหัวใจสำคัญที่ทำให้ลายยึดเกาะกับผ้าได้แน่นหนา
   04
H3 Heat Press App.
   (รีดด้วยเครื่องรีดร้อน)
   นำฟิล์มวางบนเสื้อและรีดด้วยเครื่อง Heat Press ที่ อุณหภูมิ 130-180 องศาเซลเซียส พร้อมแรงกดที่ได้มาตรฐาน จากนั้นลอกฟิล์มออกเพื่อให้ได้ลายสกรีนที่ติดแน่น สีสดคมชัด

---- block 5  title=[]
   PRODUCT CARE
H2 วิธีดูแลรักษางานสกรีน DFT
   เพื่อยืดอายุการใช้งานและคงความสวยงามของลายสกรีนให้อยู่กับเสื้อไปนานๆ เราขอแนะนำวิธีการดูแลรักษาง่ายๆ ที่ช่วยปกป้องคุณภาพของงานพิมพ์
H3 กลับด้านเสื้อก่อนซัก
   พลิกเสื้อเอาลายสกรีนไว้ด้านในก่อนซักเสมอ และไม่ควรขยี้แรงบริเวณลายสกรีนโดยตรง
H3 ใช้น้ำอุณหภูมิปกติ
   ซักด้วยน้ำอุณหภูมิปกติหรือน้ำเย็น เพื่อป้องกันกาวความร้อนเสื่อมสภาพจากการโดนน้ำร้อนจัด
H3 งดน้ำยาฟอกขาว
   หลีกเลี่ยงการใช้น้ำยาฟอกขาวและน้ำยาปรับผ้านุ่มเข้มข้น เพื่อรักษาสีสันของลายให้สดใส
H3 รีดจากด้านใน
   รีดเสื้อจากด้านใน หรือใช้ผ้ารองทับบริเวณลาย ห้ามนำเตารีดสัมผัสลายสกรีนโดยตรง

---- block 6  title=[]
   EXPERT RECOMMENDATION
H2 ข้อจำกัดของ DFT ที่ควรรู้ก่อนตัดสินใจ
H3 ความเหมาะสม
   หากเป็นลายขนาดเล็กถึงกลาง หรืองานสกรีนเฉพาะจุด (เช่น โลโก้อกซ้าย, ชื่อทีม, เบอร์หลัง) งาน DFT จะให้ความรู้สึก สวยงาม คมชัด และใช้งานได้อย่างคล่องตัว โดยไม่รู้สึกอึดอัด
H3 ข้อจำกัดที่ต้องระวัง
   เนื่องจากเนื้องานมีสัมผัสเป็นชั้นลายพิมพ์ฟิล์มบางๆ หากเป็นลายขนาดใหญ่มาก (เช่น กราฟิกทึบเต็มตัว) อาจทำให้ผู้สวมใส่รู้สึกว่าเสื้อมีความหนาและระบายอากาศได้น้อยลงในบริเวณที่สกรีน แตกต่างจากงานพิมพ์ Sublimation ที่หมึกซึมเข้าเส้นใยผ้า
   " หากมองในมุมของแบรนด์ งาน DFT คือเทคโนโลยีที่ตอบโจทย์ความยืดหยุ่น สร้างสรรค์ลวดลายได้ไร้ขีดจำกัด และถ่ายทอดไอเดียลงบนเสื้อทุกประเภทได้อย่างรวดเร็วและสมบูรณ์แบบ "
