## ข้อสรุปใหญ่ 5 ข้อ

1. **ตัวธีมใหม่แข็งแรง**: title/description ไม่ซ้ำทุกหน้า, h1 หน้าละ 1, canonical ถูก, เนื้อหา ราคา FAQ ตารางไซซ์ อยู่ใน HTML ครบโดยไม่ต้องรัน JS (บอท AI อ่านได้), URL เก่า 42 ตัวไม่มีตัวไหนกลายเป็น 404, ทุกหน้าลึกไม่เกิน 2 คลิก
2. **ปัญหาใหญ่สุดคือ "ตัวตนธุรกิจไม่ชัด"**: ที่อยู่มี 3 ชุด (264 / 109/20 / 79/177), เวลาเปิด 2 ชุด, หมุดแผนที่เก่าพาไปร้านชื่อ "FinixSports", schema เว็บเก่าชื่อ "TEAMDEE STUDIO" · ทั้ง Google และ AI ต้องเห็นชุดเดียวกันทุกที่ถึงจะเชื่อ
3. **พอเปิดธีมใหม่บนเว็บจริงที่มี Rank Math**: ข้อมูลธุรกิจจะออก 2–3 ชุดที่ขัดกัน, breadcrumb ซ้ำ 2 ชุด, รูปแชร์ทุกหน้ากลายเป็นโลโก้/รูปเก่า, ภาษาใน schema เป็น en-US · ต้องแก้ในธีม + ตั้ง Rank Math ก่อนสลับ
4. **Google ยังไม่ค่อยเห็นเรา**: ติดเฉพาะ /size-chart/ (34% ของคลิกทั้งเว็บ), หน้าแรก, /education/ · คำขายหลัก (รับทำเสื้อทีม, โปโลปัก, เสื้อกีฬา) ไม่ติด · คู่แข่งที่ชนะใส่ตัวเลขใน title (ขั้นต่ำ, ราคาเริ่ม) และราคาชัด
5. **AI ยังไม่รู้จัก TEAMDEE**: ค้น 13 คำไม่เจอเลย · นอกเว็บแทบไม่มีใครพูดถึง (ไม่มี GBP ที่ค้นเจอ, ไม่มี directory, ไม่มี Wikidata) · ไม่มี llms.txt

## แผน

### ขั้น 0 · อาร์ต/พี่ทัชตัดสิน (บล็อกข้ออื่น)
1. ที่อยู่จริงชุดเดียว (264 หรือ 109/20) + เวลาเปิด (เข้าพบหน้าร้าน กับ ตอบ LINE แยกกันไหม) + พิกัดหมุด
2. FinixSports กับ ดีดี ฟินิกซ์ / TEAMDEE เกี่ยวกันยังไง · GBP ของ TEAMDEE มีแยกหรือใช้หมุด FinixSports
3. ตัวเลขผลงาน: เว็บเก่าเขียน 5,000+ ทีม · เว็บใหม่ 2,800+ องค์กร / 10,000+ งาน (ยืนยันแล้ว) → ให้เว็บเก่า/FB ใช้ชุดเดียวกัน
4. ราคาพิมพ์ลาย (print.json ยังเป็น "[รอยืนยัน]") · อาร์ตเคยเลือกไม่ใส่ราคาบน /sublimation/ (17 พ.ย.) → ยืนยันว่ายังไม่ใส่ (AI/คู่แข่งใช้ราคาเป็นจุดอ้างอิง)
5. title ที่จะใส่ตัวเลข/คำที่เคยติดอันดับ (ดูขั้น 1 ข้อ 8)

### ขั้น 1 · โค้ดธีม (ผมทำได้เลย ~1–2 วัน)
1. filter `rank_math/json_ld`: ธุรกิจเหลือชุดเดียว `/#business`, ตัด breadcrumb ซ้ำบนหน้าธีม, WebSite ชื่อ TEAMDEE ภาษา th (ต้อง dump ค่าจริงบน staging ยืนยัน key)
2. เก็บ og:image / og:locale ของธีมไว้ตอนมี Rank Math + ทำรูปแชร์ JPG 1200×630 รายหน้า (ตอนนี้ WebP และบางหน้าเป็นแนวตั้ง)
3. LocalBusiness: ใส่ตำบล, openingHoursSpecification, priceRange, โลโก้ PNG, alternateName "ทีมดี" · อ้าง `/#business` ทุกหน้า
4. Product + AggregateOffer หน้าสินค้าที่มีราคาจริง (โปโลปัก 170–390 ฯลฯ ขั้นต่ำ 10) · ไม่ใส่ดาวรีวิว (Google ไม่นับรีวิวที่ธุรกิจเก็บเอง)
5. Breadcrumb บนหน้า = ใน schema (ไม่ตรง 21–23 หน้า) + เพิ่ม about, contact, blog, project
6. `/llms.txt` สร้างจาก site.json / prices.json / lead-times.json ตอน build (ร่างใน geo.md)
7. เก็บกวาด: canonical หน้า 404, /FAQ/ ตัวใหญ่ → 301, `/?p=` → 301, `/?s=` → /search/, ราคาเริ่มต้นใน /calculations/ ลง HTML, robots ของหน้าที่ sync, ปิด sitemap users/archives
8. title/description (รอขั้น 0 ข้อ 5): ใส่ตัวเลขจริง เช่น "เริ่ม 10 ตัว · รวม VAT" · /size-chart/ คง "S–5XL" (หน้านี้ได้คลิก 34%) · /education/ คงคำ "เสื้อรุ่น/เสื้อคณะ"

### ขั้น 2 · อาร์ตทำใน WP / Rank Math ตอนสลับธีม
- **ก่อนสลับ**: export GSC (Pages, Queries 16 เดือน, Links, Indexing) · backup เว็บเก่า + Rank Math redirects/settings
- **ตอนสลับ**: Rank Math Local SEO → TEAMDEE + NAP ชุดเดียว + โลโก้ PNG · ภาษาไทย · breadcrumb "หน้าแรก" · ลบ schema เก่า (Service/HowTo ที่อยู่ 109/20) · รูป OG ค่าเริ่ม 1200×630 · กด "สร้างหน้าที่ยังไม่มี" ให้ sitemap ครบ 42 หน้า · เปลี่ยนชื่อผู้เขียนจาก admin · unpublish /test-page/ · cookieConsent=true
- **หลังสลับ**: ส่ง sitemap ใน GSC + Bing Webmaster · request indexing 10 หน้าหลัก · ดู GSC ทุกวัน 2 สัปดาห์ · curl ทุก URL เก่าเช็ก redirect
- บทความ WP 12 เรื่อง: ลบคำว่า "โรงงาน" (~147 จุด ใน 5 เรื่องหลัก) · แก้ขั้นต่ำในบทความ DFT (เขียน 10 ตัว แต่เว็บบอก 1 ตัว)

### ขั้น 3 · เนื้อหา (สัปดาห์–เดือน)
- ย่อหน้าเปิดหน้าแรก "TEAMDEE คือ…" + กล่องข้อมูลบริษัทใน /about-us/ (ข้อความร่างใน geo.md R1–R6 ใช้แค่ข้อเท็จจริงใน repo)

- บทความใหม่: ซับลิเมชันคืออะไร · ผ้าโปโลแบบไหนดี · เลือกผู้ผลิตเสื้อทีม 8 ข้อ · ไอเดียเสื้อกีฬาสี 4 สี ฯลฯ (รายการเต็มใน keywords.md)
