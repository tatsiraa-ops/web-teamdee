## รอบงาน

1. **ผังข้อมูลกับเมนู:** products / uses / guides / routes · แถบเมนู · footer · เมนูมือถือ · ตัวเลือกสินค้าในฟอร์มติดต่อ
2. **หน้าแรก 17 ส่วน:** hero 2 สไลด์ → สินค้า 4 หมวด → กลุ่มลูกค้า → รีวิว → โลโก้ลูกค้า 2 แถว → วิดีโอ → รูปลูกค้า 3 แถว → CTA → แกลเลอรีแบบเสื้อพิมพ์ลาย → วิธีทำงาน → ผลงาน 4 แถว → CTA → FAQ → รู้จักทีมดี → บทความ / ข่าว / โซเชียล → รับประกันและติดต่อ
3. **หน้าสินค้า:** แม่แบบหน้าสินค้าตาม v4 · หน้าเสื้อแบบพิเศษ · หน้าเสื้อวอร์ม
4. **กลุ่มลูกค้า / แบบเสื้อ / ผลงาน**
5. **คู่มือ / บทความ / FAQ / เกี่ยวกับ / ติดต่อ / ค้นหา / 404 / นโยบาย**

แต่ละรอบจบด้วยการตรวจ: เทส · build · export:wp · ภาพ 3 ขนาดจอ · axe

## ข้อมูลที่ v4 ต้องการแต่ยังไม่มี

แสดงเป็น [วงเล็บ] หรือช่องว่างแบบที่ v4 ทำไว้:
- รีวิวพร้อมรูปเจ้าของคำพูดและลิงก์ต้นทาง
- คลิปรีวิว 3 คลิป
- โลโก้ลูกค้าที่ได้รับอนุญาต (ในเครื่องมี 45 ไฟล์ ยังไม่ได้อนุญาต)
- รูปออฟฟิศ ทีมงาน และโรงงาน
- ที่อยู่และวิธีนัดเข้าพบ
- เงื่อนไขรับประกันและบริการหลังการขาย
- ข่าวสารและโซเชียล
- สเปกเสื้อวอร์ม
- รายละเอียดบริการสกรีน
