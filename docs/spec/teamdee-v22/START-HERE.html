  • ชื่อหน้าสินค้าใช้ “สั่งทำเสื้อโปโลปัก” และ “สั่งทำเสื้อสกรีน” ไม่ใช้คำว่าโลโก้ในหัวข้อหลัก แต่ใช้ในคำบรรยายเพื่ออธิบายงานที่รับได้
  • หน้ารีวิวมีเพียง /project/ รวมโลโก้ รีวิวข้อความ คลิป เรื่องราวและภาพลูกค้า ไม่มีหน้ารีวิวรายกลุ่ม ตัวกรอง หรือหน้ารายโครงการ ภาพกดขยายในหน้าเดิมได้
  • ตัดหน้ารวม /use-cases/ ออก หน้าแรก Section 03 มี 5 การ์ด: บริษัท กีฬา กิจกรรม โรงเรียน หน่วยงาน กดตรงเข้าหน้ากลุ่มนั้น

  • หน้าใหม่ใช้ URL ชั้นเดียว เช่น /custom-badminton-shirts/ ไม่ใช้ /use-cases/ หรือ /customers/ นำหน้า ส่วน URL เดิมเก็บไว้ทั้งหมด
  • ลิงก์รีวิวใน SEM ทุกแคมเปญใช้ /project/ ไม่ส่งพารามิเตอร์ customer หรือ product ในรอบนี้
  • ลิงก์ hash เก่าของต้นแบบพาไปหน้ารีวิวรวมหรือ Section 03 อัตโนมัติ เว็บจริงต้องตรวจว่ามี URL เก่าเผยแพร่จริงหรือไม่ก่อนจัดทำ redirects
  • ชุดนี้มี 107 มุมมองรวมหน้าแบบสาธิต ไม่ใช่ข้อกำหนดให้ทำ 107 หน้า SEO โดยยังคง 6 หน้าสินค้า / 10 หน้ากลุ่มลูกค้า / 1 หน้ารีวิว

2. ข้อสรุปที่ตกลงแล้ว

  • หน้าสินค้า 6 ประเภท: โปโลปัก / พิมพ์ลาย / สกรีน / วอร์มพิมพ์ลาย / เบสบอล / เจอร์ซีย์ Oversize เน้นข้อมูล ผ้า ตัวเลือก ราคา ไซซ์ งานจริง และภาพกระบวนการผลิต
  • หน้ากลุ่มลูกค้า 10 กลุ่ม: บริษัท / ร้านค้า / หน่วยงาน / โรงเรียนและกีฬาสี / รุ่นและชมรม / คณะและมหาวิทยาลัย / กีฬา / แบด / วิ่ง / อีเวนต์และกิจกรรม เน้นโจทย์กลุ่ม แบบเสื้อ รีวิว และภาพลูกค้า
  • ชื่อกลุ่มบนเว็บใช้ / คั่น และใส่คำว่าเสื้อหน้าทุกชื่อ เช่น เสื้อโรงเรียน / เสื้อกีฬาสี
  • คลังแบบกราฟิกเป็นของเสื้อพิมพ์ลายโดยเฉพาะ แบ่งตามกลุ่มลูกค้า มีรหัสแบบส่งต่อไปขอราคาได้
  • หน้ารีวิวลูกค้า: Hero → โลโก้แบรนด์ที่มีหลักฐานจริงและสถิติ → รีวิวข้อความ → คลิป → เรื่องราวลูกค้า → ภาพลูกค้าสวมใส่ → ติดต่อ
  • โลโก้แบรนด์ต้องมาจากลูกค้าจริง ไม่ใส่แบรนด์ตัวอย่างเป็นหลักฐาน ความเป็นโรงงานเจ้าของเองห้ามอ้างจนยืนยันข้อเท็จจริง
  • หน้าแรกใช้ลำดับตาม v22 มี 3 บริการหลัก โลโก้หนึ่งแถว สถิติเหนือโลโก้ และเรื่องราว/สถานที่หลัง FAQ
  • หน้ากลุ่มลูกค้ามีภาพลูกค้าหลายแถวแยกจากคลิป หน้าสินค้าไม่ต้องมีแกลเลอรีภาพลูกค้าขนาดใหญ่

3. ข้อมูลและไฟล์ที่เจ้าของแบรนด์ควรส่งเพิ่ม

ชุดข้อมูลไฟล์ที่ควรส่งสิ่งที่ต้องกำกับ
แบรนด์โลโก้ SVG / AI / PDF และ PNG โปร่งใส, คู่มือสี/ฟอนต์, โฟลเดอร์แบรนด์ทีมดี, เอกสารโพสต์ปักหมุดฉบับล่าสุดระบุเวอร์ชันที่ใช้จริง สิทธิฟอนต์ และผู้อนุมัติข้อความ
สินค้าภาพหน้า–หลัง รายละเอียดผ้า/ปัก/สกรีน ภาพสวมใส่ ตารางผ้า สี ทรง ไซซ์จับคู่รหัสสินค้า ชื่อผ้า หน่วยวัด และคุณสมบัติที่ยืนยันได้
ราคาและเงื่อนไขตารางราคาแยกประเภท/จำนวน ขั้นต่ำ ระยะผลิต ตัวเลือกเสริม ค่าแพ็ก/ส่ง ภาษีบอกวันที่เริ่มใช้ราคา รายการรวม/ไม่รวม และจุดเริ่มนับเวลาผลิต
แบบพิมพ์ลายภาพแบบหน้า–หลังความละเอียดสูงและไฟล์ต้นฉบับรหัสจริง กลุ่มลูกค้า สีที่ปรับได้ สถานะแบบที่ขายได้ และสิทธิใช้งาน
รีวิวข้อความจริง รูปเจ้าของคำพูด ภาพลูกค้า คลิป และโลโก้แบรนด์ลูกค้าชื่อทีม กลุ่มลูกค้า ประเภทเสื้อ คะแนนจริง วันที่ ลิงก์ต้นทาง และสิทธิเผยแพร่
สถานที่และการผลิตภาพออฟฟิศ ทีมงาน และภาพขั้นตอนผลิตแยกประเภทเสื้อสถานที่จริง คำอธิบายกระบวนการ ความสัมพันธ์กับโรงงาน และหมุดนัดหมาย
ติดต่อและระบบเบอร์โทร LINE URL โซเชียล อีเมลรับฟอร์ม ที่อยู่ เวลาติดต่อผู้รับผิดชอบตอบลูกค้า ฟิลด์ฟอร์มที่ต้องใช้ และระบบเก็บข้อมูล
โดเมนและการวัดผลบัญชีโดเมน/โฮสติ้ง CMS Analytics Search Console และ URL เว็บเดิมเชิญผู้พัฒนาด้วยสิทธิที่จำเป็น ไม่ส่งรหัสผ่านในชุดไฟล์หรือหน้า Sites สาธารณะ

5. ข้อมูลที่ต้องยืนยันก่อนขึ้นเว็บจริง

  • สถิติอ้างอิงปี 2026: 8 ปีนับจากเริ่มงานในปี 2018 / 2,800+ องค์กร / 10,000+ งานผลิต เป็นคนละหน่วย ไม่ใช่จำนวนเสื้อหรือจำนวนรีวิว
  • ปีเริ่มงาน 2018 ไม่ใช่ปีจดทะเบียนบริษัท: บริษัท ดีดี ฟินิกซ์ จำกัด จดทะเบียน 19 มกราคม 2021
  • ตัวอย่างผ้าฟรีโดยไม่วางมัดจำ ไม่เท่ากับแจกเสื้อตัวอย่างฟรีทุกออเดอร์
  • แจ้งปัญหาจากการผลิตภายใน 7 วัน และแบบเดิมราคาเดิมภายใน 30 วัน ต้องใช้ข้อความเงื่อนไขที่เจ้าของธุรกิจตรวจแล้ว
  • ออกใบเสร็จ / ใบกำกับภาษี รับบัตรเครดิตและวางบิลได้ แต่ต้องยืนยันชนิดบัตร ค่าธรรมเนียม และเกณฑ์วางบิล
  • ขั้นต่ำ เวลาผลิต ราคาของแต่ละสินค้า และคุณสมบัติผ้าต้องมีหลักฐานจริง ช่องว่างยังไม่ใช่คำสัญญาต่อลูกค้า
  • ยืนยันหมุดเข้าพบและความสัมพันธ์กับโรงงานก่อนใช้ภาพหรือถ้อยคำอ้างความเป็นเจ้าของ

6. งานที่ผู้พัฒนาต้องทำต่อ

  1. ออกแบบภาพลักษณ์จริงจากแบรนด์ แล้วใช้ Sitemap และลำดับเนื้อหา v22 เป็นฐาน
  2. สร้าง URL จริงแยกหน้า ไม่ใช้ hash route จากไฟล์ wireframe เป็นโครง SEO บนเว็บจริง
  3. กำหนดประเภทข้อมูลใน CMS: สินค้า กลุ่มลูกค้า แบบเสื้อ รีวิว บทความ และข้อมูลบริษัท
  4. แทนรหัส WF และข้อมูลใน [ ] ด้วยข้อมูลที่อนุมัติ ไม่เผยแพร่หน้าร่างเป็นหน้า SEO
  5. เชื่อมปุ่มขอราคาให้ส่งประเภทเสื้อ กลุ่มลูกค้า และรหัสแบบจริง พร้อมเชื่อม LINE/ฟอร์ม/ระบบรับข้อมูล
  6. ตั้ง Title, Meta description, H1, URL หลัก และลิงก์ภายในให้ตรงหน้า รวมคำค้นที่มีเจตนาเดียวกัน
  7. หน้ารีวิวใช้ /project/ หน้าเดียว ไม่มีตัวกรอง หน้ารายกลุ่ม หรือหน้ากรณีศึกษาแยก
  8. ทำแผน URL เก่า → ใหม่ก่อนย้ายเว็บ เพื่อตรวจและตั้ง redirect ที่ตรงเนื้อหา
  9. บีบอัดรูป ใส่ข้อความแทนภาพจากภาพจริง โหลดวิดีโอเมื่อกด และรองรับการใช้คีย์บอร์ด
  10. ทดสอบมือถือ ฟอร์มจริง ลิงก์ ตัวกรองแบบเสื้อ รหัสแบบ และการวัดผล พร้อมตรวจนโยบายข้อมูลก่อนเปิดใช้งาน

7. ขอบเขตของต้นแบบ

ปุ่ม LINE โทร ดาวน์โหลดตัวอย่าง และการส่งฟอร์มบางส่วนเป็นการจำลอง ไม่มีการส่งข้อมูลลูกค้าจริง ไฟล์ HTML เป็นต้นแบบอินเทอร์แอกทีฟ ไม่ใช่ระบบร้านค้า/ชำระเงิน/CMS พร้อมใช้งาน และการจัดชื่อ SEO ในไฟล์ไม่ได้รับรองอันดับค้นหา

ให้ยึด v22 และชุดนี้เป็นจุดเริ่มงาน ไม่ใช้ไฟล์ก่อนหน้าในโฟลเดอร์ versions หรือ brief เก่าที่ขัดกับข้อสรุปล่าสุด
