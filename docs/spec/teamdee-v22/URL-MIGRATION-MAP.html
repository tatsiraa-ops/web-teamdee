5. เช็กลิสต์ส่งมอบ

  • หน้าใหม่ใช้ URL ชั้นเดียว เติม custom เฉพาะ 9 หน้ารับสั่งทำใหม่ ไม่เติมในคู่มือ แบบเสื้อ รีวิว บทความ และหน้าระบบ
  • URL เดิมทั้งหมดคงเดิม รวม /corporate/ /size-chart/ และหมวดบทความหลายชั้น ไม่เติม custom ย้อนหลัง
  • แยกตารางเปลี่ยนแผน v21 → v22 ออกจาก URL ที่เคยออนไลน์ ไม่สร้าง redirect จากชื่อแผนโดยอัตโนมัติ
  • คง /corporate/ และ /size-chart/ ให้ตอบ 200 ที่ URL เดิม ไม่ redirect ไปแผน v20
  • เนื้อหาเดิมที่ถูกต้องและมีผล SEO ต้องย้ายด้วย ไม่ใช่คง URL แต่ลบเนื้อหาทั้งหมด
  • 12 บทความเดิมและหน้าเดิมที่ไม่มี wireframe ต้องย้ายจาก CMS เดิม ไม่ใช้ไฟล์ PAGE-CONTENT แทนเนื้อหาเดิม
  • ไม่สร้าง 301 จาก URL ที่เป็นเพียงแผน v20; ถ้าเคยเผยแพร่จริงต้องตรวจและเพิ่ม mapping
  • หน้า /project/ เป็นรีวิวหน้าเดียว; ไม่มีหน้ารายกลุ่มหรือรายโครงการใหม่
  • ทำ staging แบบ noindex แต่เว็บจริงต้องไม่รับ noindex ทั้งเว็บหรือ CSP ของกรอบ preview ไปโดยไม่ตรวจ
  • ตรวจ canonical, internal links, sitemap, รูป, แบบฟอร์ม, analytics และ Search Console ก่อนเปิดจริง
  • เก็บรายงานก่อน/หลังย้าย ตรวจ 404 การจัดทำดัชนี คลิก และผู้ติดต่อ; ไม่รับรองอันดับคงเดิม

ข้อมูล URL มาจาก Sitemap และเมนูสาธารณะ ยังไม่ใช่รายการครบจาก CMS หรือรายงานอันดับจริงจาก Search Console
